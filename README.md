# 🍔 FoodWeb — React Food Ordering Application

![React](https://img.shields.io/badge/React-18-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5-purple)

FoodWeb is a **React-based food ordering web application** built to simulate **real-world machine coding round requirements**.  
The project focuses on **clean component design, state management, and scalable frontend architecture**—not just UI.

---

## 🔍 Why This Project?

This project was intentionally built to:
- Practice **React machine coding problems**
- Apply **JavaScript fundamentals in real scenarios**
- Write **clean, readable, interview-friendly code**
- Handle **cart logic and state consistency**

---

## 🚀 Key Features

- 🍽️ Menu listing with reusable components
- 🛒 Add / remove items from cart
- ➕ Increment / decrement item quantities
- 💰 Real-time cart price calculation
- 🔁 State-driven UI updates
- 📱 Responsive layout using Bootstrap

## 🧠 Machine Coding Learnings (Interview Focus)

This project helped reinforce **core concepts tested in frontend interviews**:

### 🔹 React & State Management
- Avoided **direct state mutation**
- Used **functional updates** to prevent stale state bugs
- Designed **single source of truth** for cart data

### 🔹 Component Design
- Broke UI into **small, reusable components**
- Passed data via **props** with clear responsibilities
- Maintained **separation of concerns**

### 🔹 JavaScript Fundamentals
- Object-based cart storage for O(1) access
- Conditional rendering patterns
- Event handling and controlled updates

### 🔹 Performance & Best Practices
- Minimal re-renders
- Predictable state updates
- Clean folder structure and naming

These concepts are directly transferable to **machine coding rounds and real-world React projects**.

## ▶️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/rydhammahajan/foodWeb.git
````

### 2️⃣ Navigate to the project

```bash
cd foodWeb
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start development server

```bash
npm start
```

App runs on:

```
http://localhost:3000
```
